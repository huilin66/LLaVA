## Intended baseline workflow

1. Supply the licensed `cubit-det` data, its annotation file, and the base LLaVA/Vicuna/CLIP checkpoints.
2. Restore or provide the DeepSpeed configuration referenced by the training script.
3. Run `scripts/v1_5/finetune_lora_detection.sh` after replacing machine-specific paths and verifying GPU capacity.
4. Merge the adapter with `scripts/v1_5/lora_merge_detection.sh` after replacing its absolute paths.
5. Run `scripts/predict_detection.py` or `scripts/v1_5/predict_detection.sh` on a versioned image set and archive raw responses as well as parsed tables.
6. Only after the baseline is reproducible should a separate vLLM runner be introduced for a matched comparison.
